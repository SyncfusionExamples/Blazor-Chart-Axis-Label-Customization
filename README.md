# Blazor Chart Axis Label Customization

## Overview

This sample demonstrates how to customize axis labels in a Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts). The implementation focuses on improving axis label readability and presentation by applying axis-label customization options within chart axis configuration. It serves as a practical reference for developers who need to control how category or value labels are displayed in chart visualizations to improve clarity, reduce overlap, and enhance the overall user experience.

## Key Features

- Uses the Syncfusion `SfChart` component to render chart visualizations.
- Demonstrates customization of chart axis label appearance and rendering behavior.
- Shows how axis labels can be configured through chart axis settings.
- Includes chart axis configuration examples designed to improve label readability.
- Provides a working sample for implementing customized chart-axis labels in a Blazor Server application.
- Demonstrates chart presentation techniques related to axis label display and layout.
- Includes sample chart data used to render customized axis labels.
- Illustrates practical chart configuration patterns for business reporting and data visualization scenarios.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `ChartAxisLabels.sln`

3. Restore all NuGet packages.
4. Set the startup project to `ChartAxisLabels` if required.
5. Build the solution.
6. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository directory.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed in the terminal output.
